# NLA — Numerical Linear Algebra

A collection of Jupyter notebooks covering fundamental topics in numerical linear algebra, with Python implementations and examples.

## Contents

- **[LU Decomposition](src/LU%20decomposition.ipynb)** — Gaussian elimination and LU factorization
- **[Cholesky Decomposition](src/Cholesky%20decomposition.ipynb)** — Cholesky factorization for symmetric positive-definite matrices
- **[QR Decomposition](src/QR%20decomposition.ipynb)** — Gram-Schmidt, Householder, and Givens methods
- **[Least Squares](src/Least%20Squares.ipynb)** — Normal equations, QR-based, and SVD-based solutions

## Getting Started

Clone the repository and open the notebooks with Jupyter:

```bash
git clone https://github.com/winmpkid/NLA.git
cd NLA
jupyter notebook
```
